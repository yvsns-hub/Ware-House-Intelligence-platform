## 🧠 The Philosophy

Traditional warehouse management is reactive — an order comes in, stock runs out, someone panics, something gets delayed.

**WarehouseIQ inverts that.**

It monitors 4 geographically distributed warehouse hubs, runs every stock shortage through a 3-level decision cascade, and treats order delays as the *absolute last resort* — not the first response.

The platform doesn't just show dashboards. It runs a **Decision Engine** that automatically:

1. 🔍 Scans sibling warehouse hubs for available stock
2. 🤖 Consults an AI recommendation engine for alternative strategies
3. ⏳ Only delays an order when every other option is exhausted

## ⚡ The 3-Level Decision Engine

This is the architectural heart of WarehouseIQ. When an order can't be fulfilled from local stock, the system **never immediately delays it**. Instead:

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ORDER RECEIVED — STOCK CHECK                     │
│                                                                     │
│  Local stock sufficient?                                            │
│  ├── YES → ✅ ALLOCATE immediately                                  │
│  └── NO  → Enter 3-Level Cascade ↓                                 │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │ LEVEL 1: CROSS-HUB INVENTORY TRANSFER                      │    │
│  │                                                             │    │
│  │ Scan Hub-01 (NY), Hub-02 (LA), Hub-03 (TX), Hub-04 (IL)   │    │
│  │ ├── Found stock in another hub?                             │    │
│  │ │   └── YES → 🚚 Recommend inter-hub transfer              │    │
│  │ │            "Inventory transfer approved from Hub B"       │    │
│  │ └── NO  → Escalate to Level 2 ↓                            │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │ LEVEL 2: AI RECOMMENDATION ENGINE                           │    │
│  │                                                             │    │
│  │ Strategies: Partial Fulfillment | Substitute SKU |          │    │
│  │             Priority Reorder | Split Shipment               │    │
│  │ ├── AI found a viable strategy?                             │    │
│  │ │   └── YES → 🤖 Execute AI recommendation                 │    │
│  │ │            "AI recommends partial fulfillment for SLA"    │    │
│  │ └── NO  → Escalate to Level 3 ↓                            │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │ LEVEL 3: DELAY ORDER (LAST RESORT ONLY)                     │    │
│  │                                                             │    │
│  │ ⚠️  This is the FINAL option — never the first response     │    │
│  │ └── ⏳ "Order delayed due to global stock shortage"         │    │
│  └─────────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────────┘
```

## 🚀 Quick Start

### Prerequisites

- **Node.js** ≥ 18
- **PostgreSQL** database (local or hosted — Supabase, Neon, Railway)
- **Firebase** project with Google Auth enabled

### 1. Clone & Install

```bash
git clone https://github.com/yvsns-hub/Ware-House-Intelligence-platform.git
cd Ware-House-Intelligence-platform
npm install
```

### 2. Configure Environment

```bash
cp .env.example .env
```

Edit `.env` with your credentials:

```env
DATABASE_URL="postgresql://user:password@host:5432/warehouse_db?schema=public"
OPENROUTER_API_KEY="your-openrouter-api-key"
OPENWEATHER_API_KEY="your-key"

# Firebase
NEXT_PUBLIC_FIREBASE_API_KEY="..."
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN="..."
NEXT_PUBLIC_FIREBASE_PROJECT_ID="..."
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET="..."
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID="..."
NEXT_PUBLIC_FIREBASE_APP_ID="..."
```

### 3. Initialize Database

```bash
npx prisma generate
npx prisma db push
npm run prisma:seed    # Seeds 100 products + employees
```

### 4. Launch

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — sign in with Google, select your hub, and start managing.
